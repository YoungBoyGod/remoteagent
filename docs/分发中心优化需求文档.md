# 分发中心页面优化需求文档

## 1. 需求背景

分发中心页面存在以下用户体验问题，需要进行优化：

### 1.1 按钮配色问题
- **问题描述**: 操作按钮文字看不清，对比度不足
- **影响**: 用户难以识别可点击的按钮，影响操作效率

### 1.2 历史记录Tab布局问题
- **问题描述**: 历史记录部分的页签（Tab）数量过多且存在错位
- **影响**: 占用过多横向空间，布局不美观，用户体验差

## 2. 优化目标

### 2.1 按钮配色优化
- 提高按钮文字与背景的对比度
- 确保按钮文字清晰可见
- 统一按钮样式规范

### 2.2 Tab布局优化
- 减少Tab数量，优化分组
- 修复页签错位问题
- 提升布局美观度和可用性

## 3. 具体优化方案

### 3.1 按钮配色优化

#### 3.1.1 问题分析
- 原来的按钮使用 `type="primary" text` 组合，文字对比度低
- 部分按钮使用 `text` 属性，导致在某些背景色下难以识别

#### 3.1.2 解决方案
1. **移除 `text` 属性**
   - 所有主要操作按钮使用标准 `type` 属性
   - 不再使用 `text` 样式

2. **统一按钮类型**
   - 主要操作按钮：`type="primary"` (蓝色，高对比度)
   - 次要操作按钮：`type="info"` (灰色，中等对比度)
   - 危险操作按钮：`type="danger"` (红色，高对比度)

3. **具体按钮优化**
   - "复制链接"按钮：从 `text` 改为 `type="info"`
   - "编辑"按钮：移除 `text` 属性，使用 `type="primary"`
   - "删除"按钮：移除 `text` 属性，使用 `type="danger"`
   - "重发"按钮：移除 `text` 属性，使用 `type="primary"`
   - "保存"、"确认分发"等操作按钮：移除图标，仅保留文字

#### 3.1.3 涉及文件
- `DistributionRecords.vue` - "重发"按钮优化
- `ReleaseNotes.vue` - "编辑"/"删除"按钮优化
- `EncryptionQueue.vue` - 所有按钮优化

### 3.2 历史记录Tab布局优化

#### 3.2.1 问题分析
- 原来有7个状态标签，占用大量横向空间
- 状态分散，用户需要频繁切换
- 页签存在错位问题，视觉效果不佳

#### 3.2.2 解决方案

**1. 状态分组合并**

将7个Tab合并为4个，按业务逻辑分组：

| 原状态 | 合并后分组 | 说明 |
|--------|-----------|------|
| 全部 | 全部 | 所有状态 |
| 排队中 | 进行中 | `pending` |
| 加密中 | 进行中 | `encrypting` |
| 上传中 | 进行中 | `uploading` |
| 已上传 | 已完成 | `uploaded` |
| 已发送 | 已完成 | `sent` |
| 已过期 | 失败 | `failed` |

**2. Tab样式优化**

```css
/* 修复错位问题 */
.status-tabs :deep(.el-tabs__item) {
  padding: 0 20px !important;  /* 确保padding生效 */
  font-weight: 500;
  height: 36px;
  line-height: 36px;
  min-width: 80px;              /* 防止标签过窄 */
  text-align: center;           /* 居中对齐文字 */
}

.status-tabs :deep(.el-tabs__nav) {
  border-radius: 6px;
  background: #f5f7fa;
  padding: 4px;
  height: 36px;
  display: flex;                /* 修复错位 */
  align-items: center;          /* 垂直居中 */
}

/* 激活状态样式 */
.status-tabs :deep(.el-tabs__item.is-active) {
  background: #409eff;          /* 蓝色背景 */
  color: #fff;                  /* 白色文字 */
  border-radius: 4px;
}

/* 悬停状态样式 */
.status-tabs :deep(.el-tabs__item:hover:not(.is-active)) {
  background: #e8f0fe;          /* 浅蓝色背景 */
  color: #409eff;               /* 蓝色文字 */
}
```

**3. 样式特点**
- **Tab高度**: 36px
- **激活Tab**: 蓝色背景 + 白色文字
- **悬停Tab**: 浅蓝色背景 + 蓝色文字
- **圆角设计**: 6px 外框 + 4px 内标签
- **标签数量**: 4个 (全部/进行中/已完成/失败)

#### 3.2.3 涉及文件
- `DistributionRecords.vue` - statusTabs数组优化 + 样式优化
